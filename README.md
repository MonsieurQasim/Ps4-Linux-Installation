# Ps4-Linux-Installation
# Installing Linux on PlayStation 4

## Overview

This project documents the process of installing and running a Linux operating system on a PlayStation 4 console.

The objective was to repurpose gaming hardware into a functional Linux-based computer, exploring hardware compatibility, operating system deployment, system configuration, and Linux administration.

## Project Objectives

- Deploy a Linux operating system on PlayStation 4 hardware.
- Configure the system to boot into a Linux environment.
- Explore hardware compatibility and resource utilization.
- Test the functionality and performance of the Linux installation.
- Repurpose existing hardware for general-purpose computing.

## Technologies & Tools

- Linux Arch partition
- PlayStation 4 hardware
- USB with more than 22 GB
- Linux boot environment
- Computer with FileZilla and Rufus

## Project Documentation

Detailed documentation covering the installation process, system configuration, and troubleshooting will be provided in this repository.

## Results

Successfully installed and booted Linux on PlayStation 4 hardware, transforming the console into a Linux-based computing environment.

## Disclaimer

This project is intended for educational and research purposes. Hardware compatibility and installation procedures may vary depending on the PlayStation 4 model and firmware version.
